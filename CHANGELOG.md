# Changelog

All notable changes to the AI Orthopaedic Assistant project will be documented in this file.

## [1.0.0] - 2026-08-04

### Added
- Production-level repository structure with standardized `frontend/`, `backend/`, `models/`, `docs/`, `datasets/`, and `scripts/` directories.
- MobileNetV2 Trained Bone Fracture CNN Classifier integration.
- Grad-CAM heatmap visualization overlay engine.
- ANN regression model for personalized fracture healing time estimation.
- Knowledge-based ML rehabilitation recommendation engine.
- Geolocation-based nearby orthopedic hospital locator with Google Maps routing.
- Supabase authentication integration.
- SQLite prediction history database with CSV and PDF export functionality.
- Vercel Serverless deployment compatibility with `vercel.json` rewrites and WSGI handler.
- Modern security headers, upload sanitization, and CORS middleware.
