# Contributing to AI Orthopaedic Assistant (Dr X)

Thank you for considering contributing to the AI Orthopaedic Assistant project!

## Code of Conduct

Please help maintain a welcoming, professional, and supportive environment for all contributors.

## Development Workflow

1. **Fork the Repository**: Create your own feature branch.
2. **Setup Local Environment**:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. **Run the Application**:
   ```bash
   python app.py
   ```
4. **Submit a Pull Request**:
   - Ensure all code is properly formatted and tested.
   - Describe changes and verification steps clearly.

## Reporting Issues

If you encounter bugs or have feature suggestions, please open a GitHub Issue with:
- Summary of the problem
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Python version, Browser)
